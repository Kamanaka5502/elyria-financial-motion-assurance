# Wrapper Boundary

## Public Wrapper

Elyria Motion Guard is a bounded commercial wrapper.

It exposes a simple motion-admission surface.

## Included

```text
payment-intent evaluation
invariant routing
admission posture
non-admission posture
receipt generation
replay verification
```

## Not Included

```text
protected kernel substrate
private mathematical substrate
production treasury adapters
payment rail integrations
custody infrastructure
banking platform functionality
regulatory certification
legal certification
```

## Governance Order

```text
kernel governance
  -> invariant resolution
  -> logic word
  -> gate
  -> chute
  -> receipt
```

The wrapper exposes outcomes.

The protected substrate remains private.
